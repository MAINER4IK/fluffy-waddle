## тематика

мемный сайт standoff 2.

## Описание проекта

В рамках задания был создан небольшой сайт на тему игры Standoff 2.

Сайт состоит из одной страницы, на которой размещены:

* заголовок сайта
* изображение с игрой Standoff 2
* строка из песни [Standoff 2 music](https://genius.com/Dj-haeshka-standoff-2-music-lyrics) автора DJ HAESHKA.

Для создания сайта использовался HTML и CSS. 
- HTML отвечает за структуру страницы

- CSS используется для оформления внешнего вида сайта: цвета, шрифта, размеров элементов и их расположения.

## Структура проекта

* `index.html` — структура страницы;
* `123/style.css` — оформление сайта;
* `README.md` — описание проекта;
* `standoff2.jpg` — картинка для сайта.
